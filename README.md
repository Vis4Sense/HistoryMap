# HistoryMap

Initialised with [vite-vue3-browser-extension-v3](https://github.com/mubaidr/vite-vue3-browser-extension-v3).

An ongoing rebuild of HistoryMap ([old branch](https://github.com/Vis4Sense/HistoryMap/tree/mv3)), migrating to [mv3](https://developer.chrome.com/docs/extensions/develop/migrate/what-is-mv3) and [vue](https://vuejs.org/).

## Status

| Feature | Status | Note |
| --- | --- | --- |
| Capture page history | 🔄 In Progress | MVP done ✅ |
| Curate information (e.g., highlight & tagging) |  🔄 In Progress | Highlight is supported ✅ |

## Usage

1. Clone the project
2. run `pnpm i` to install dependencies
3. run `pnpm build` (or `pnpm dev` to run in develop mode)

Load the extension (`dist/chrome`) to your browser when using it for the first time.
